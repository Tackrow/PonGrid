# PonGrid

すべてのモニターに、自分だけのグリッドを。

PonGridは、画面全体に目盛りを重ねるmacOSのメニューバーアプリです。グリッドはクリックを通すため、いつものアプリをそのまま操作できます。

## 主な機能

- モニターごとに表示・形・細かさ・線の色や太さを設定し、自動保存。
- 四角、三角、四角＋対角線、ドットの4種類。ドットの直径・色・不透明度も設定できます。
- ポインタがある面や周辺の線・点をハイライト。周辺を徐々に透過するモードも用意。ドットの面ハイライトは4点に囲まれた区画を塗り、点を残して枠線を表示しません。
- 自由な位置に点と線を置き、距離・角度・四角の幅と高さを計測。交点へのスナップも選べます。
- 「線を消す」で1本ずつ削除。「選択・移動」ではその場の削除ボタン・Deleteキーも使え、⌘Zで戻せます。
- 計測ラベルの固定・移動、pt／描画pxのコピー、追加・削除・移動の取り消し／やり直し。
- 範囲・原点・四辺余白、4／8 ptのグリッドと主目盛り。
- 名前付きプリセット・作業セット、JSONの書き出し／読み込み。
- グローバルショートカットで一括表示・画面別表示・一時非表示を切り替え。
- 設定画面、メニューバー、距離・角度のカードにLiquid Glassを採用。
- アプリ内で更新確認と自動チェックのON/OFF。インストール前に確認します。

## ダウンロード

[最新版のDMGをダウンロード](https://github.com/Tackrow/PonGrid/releases/latest/download/PonGrid-latest.dmg) · [リリース履歴](https://github.com/Tackrow/PonGrid/releases)

DMGを開き、PonGridをApplicationsフォルダへドラッグしてください。配布アプリとDMGはDeveloper ID署名・Appleの公証に対応しています。配布ファイルの検証用に`SHA256SUMS`も添付しています。

macOS 14以降。Apple Silicon / Intelの両方に対応。Liquid GlassはmacOS 26以降で使用し、macOS 14・15では半透明の表示になります。

## 使い方

アプリを起動し、モニターごとに設定します。設定画面を閉じても常駐します。メニューバーのアイコンから一括表示やモニター別スイッチを操作できます。

「計測と範囲」から道具を選ぶと編集パレットが開きます。点はクリック、距離や四角はドラッグで計測。「線を消す」で対象を確認しながら1本ずつクリックして削除できます。「選択・移動」で線を選んだ場合は削除ボタンかDeleteキー。端の点とほかの線は残り、⌘Zで取り消せます。「完了」で通常のクリック透過へ戻ります。

編集を開かずに点を置くにはControl＋Optionを押したまま順にクリックします。キーは設定でOption、Command＋Shiftにも変更できます。

線にホバーすると距離、2本の線がつながる点や円弧にホバーすると角度を表示します。pxはモニター倍率を反映した描画ピクセルです。mm・cm・inchはモニター情報からの概算で、情報を取得できない画面では実寸を表示しません。グリッドの色・間隔・形を変更しても、計測の位置と接続は保持します。点は全モニター合計50個まで自動保存されます。

アプリの「アップデートと応援」から、更新確認と終了時の応援案内のON/OFFを設定できます。
